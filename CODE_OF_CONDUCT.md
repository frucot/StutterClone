# Code of conduct

This project follows a simple standard: be respectful, stay on topic, and assume good intent.

## Expected

- Courteous, technical discussion
- Constructive review of code and ideas
- No harassment, insults, or personal attacks
- No posting of others' private information

## Not acceptable

- Trolling, hate speech, or sexualized language
- Publishing malware, exploits against third-party systems, or credentials
- Spamming issues or pull requests

## Enforcement

Maintainers may warn, edit, or ban contributors who break these rules. Report problems to the maintainer via GitHub ([@frucot](https://github.com/frucot)).

This summary is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/) spirit for a small audio-plugin project.
