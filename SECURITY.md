## Reporting a vulnerability

Do **not** open a public GitHub issue for security problems.

Please use [GitHub private vulnerability reporting](https://github.com/frucot/StutterClone/security/advisories/new) if it is enabled, or email the maintainer through the GitHub profile [@frucot](https://github.com/frucot).

Include:

- a description of the issue and its impact
- steps or a proof of concept if you have one
- affected version / commit

You should receive an acknowledgement when the report is seen. Fixes will be released as a new version and credited if you want to be named.
